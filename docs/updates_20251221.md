# Resume Agent 开发日志 - 2025-12-21

## 1. 架构升级：多智能体协同 (Multi-Agent Orchestration)
今晚我们将系统从简单的顺序流升级为了复杂的并行协同架构：
- **Router (路由层)**：识别用户意图，支持多意图并行分发。
- **Parallel Workers (并行执行层)**：`InfoWorker`, `ExperienceWorker`, `SkillWorker` 并行运行，极大提升了响应速度。
- **InferenceWorker (常识校验层)**：新增的“猎头/HR”视角，专门负责检查简历的时间线冲突（Gap/Overlap）、职级合理性及技能关联性。
- **Aggregator (汇总层)**：整合所有 Worker 的结果及推理洞察，生成最终的友好回复。

## 2. 技术栈深化
- **LangChain LCEL & Jinja2**：
  - 全面迁移至 LangChain 表达式语言 (LCEL)。
  - 引入 Jinja2 模板引擎处理提示词，解决了 JSON 结构中 `{}` 与 LangChain 变量冲突的问题。
- **异步并发控制**：
  - 使用 `asyncio.gather` 实现 Worker 的并行调用。
  - 使用 `asyncio.Queue` 捕获并行任务中的实时工具调用日志，并通过 SSE 流式推送到前端。
- **LLM Tool Calling**：
  - `BaseAgent` 实现了完整的工具调用循环（Tool-calling Loop）。
  - 新增 `edu_date_predictor` 工具，利用逻辑推理解决教育经历中“至今”导致的幻觉问题。

## 3. 前端 UI 革命性改进
- **横向并行布局**：当多个专家并行工作时，UI 会动态创建一个横向网格（Grid），实时展示每个专家的思考过程。
- **实时计时器**：引入了带动画效果的 Pulse 计时器，实时显示处理时长。
- **调试透明化**：每条消息下方都会标注：`[Agent名称] 模型: XXX | 耗时: X.Xs`。
- **交互增强**：为用户消息增加了“重试”按钮，支持中断当前请求并重新发起。

## 4. 关键问题解决 (Bug Fixes)
- **教育日期幻觉**：通过 `edu_date_predictor` 工具，根据学位类型（本科/硕士）自动推断合理的毕业年份，并标注“(预计)”。
- **SSE 稳定性**：修复了 EventSource 监听器变量名错误及连接中断处理。
- **Prompt 变量校验**：解决了 LangChain 提示词模板中变量缺失导致的 `INVALID_PROMPT_INPUT` 错误。

## 5. 未来展望

- 增加简历 PDF 实时预览功能。
- 支持更多维度的职业建议（如：面试题预测）。
