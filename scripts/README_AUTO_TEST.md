# 自动测试脚本使用说明

## 概述

`auto_test_first_message.py` 是一个自动测试脚本，用于测试系统的第一句话处理流程。它会：

1. 自动发送测试消息："你好我是张三，过完年正好36啦，毕业于北京大学计算机科学本科"
2. 监控SSE流式响应
3. 实时显示处理状态和结果
4. 自动排查错误并给出解决建议
5. 保存完整的测试结果到JSON文件

## 使用方法

### 方法1: 使用 Makefile（推荐）

```bash
make test-auto
```

### 方法2: 直接运行Python脚本

```bash
# 确保在项目根目录
PYTHONPATH=. python scripts/auto_test_first_message.py
```

### 方法3: 使用Shell脚本

```bash
bash scripts/run_auto_test.sh
```

## 前置条件

1. **服务器必须运行**：确保API服务已启动
   ```bash
   make dev
   ```

2. **依赖已安装**：确保项目依赖已安装
   ```bash
   make install
   ```

## 功能特性

### 1. 服务器健康检查
- 自动检查服务器是否运行
- 如果服务器未运行，会给出明确的错误提示

### 2. 实时监控
- 实时显示SSE流式响应
- 彩色输出，便于区分不同类型的事件：
  - 🟢 成功消息（绿色）
  - 🔴 错误消息（红色）
  - 🟡 警告消息（黄色）
  - 🔵 信息消息（蓝色）
  - ⚪ 普通消息（白色）

### 3. 事件分类
脚本会自动分类和显示：
- **状态消息**：处理进度和状态更新
- **工具调用**：系统调用的工具信息
- **最终响应**：完整的处理结果
- **错误信息**：任何错误和异常

### 4. 错误排查
如果测试失败，脚本会：
- 分析错误类型
- 提供可能的解决方案
- 显示事件历史
- 保存完整的错误信息

### 5. 结果保存
每次测试都会自动保存结果到：
```
scripts/test_result_YYYYMMDD_HHMMSS.json
```

结果文件包含：
- 所有接收的事件
- 最终响应
- 错误信息（如果有）
- 时间戳和耗时
- 状态消息和工具调用记录

## 配置选项

可以在脚本中修改以下配置：

```python
# API地址
API_BASE_URL = "http://localhost:8000"

# 测试消息
TEST_MESSAGE = "你好我是张三，过完年正好36啦，毕业于北京大学计算机科学本科"

# Session ID（默认使用时间戳）
SESSION_ID = f"test_session_{int(time.time())}"

# 超时时间（秒）
TIMEOUT = 300  # 5分钟

# Agent类型
agent_type = "planner_worker"  # 或 "dual_track"
```

## 故障排查

### 问题1: 服务器连接失败

**错误信息**：
```
✗ 无法连接到服务器 http://localhost:8000: ...
```

**解决方案**：
1. 确保服务器已启动：`make dev`
2. 检查端口8000是否被占用
3. 确认API_BASE_URL配置正确

### 问题2: 请求超时

**错误信息**：
```
✗ 请求超时（300秒）
```

**解决方案**：
1. 检查服务器日志，查看是否有卡住的请求
2. 增加TIMEOUT值（如果处理确实需要更长时间）
3. 检查网络连接和API响应速度

### 问题3: JSON解析错误

**错误信息**：
```
⚠ JSON解析失败: ...
```

**解决方案**：
1. 检查服务器返回的SSE格式是否正确
2. 查看服务器日志，确认是否有格式问题
3. 检查API路由配置

## 高级用法

### 自定义测试消息

修改脚本中的 `TEST_MESSAGE` 变量，或通过命令行参数传递（需要修改脚本支持）。

### 测试不同的Agent类型

修改 `send_message_and_monitor` 调用中的 `agent_type` 参数：
- `"planner_worker"` - Planner-Worker架构
- `"dual_track"` - Dual-Track架构

### 批量测试

可以创建一个包装脚本，循环调用测试脚本进行多次测试。

## 注意事项

1. **确保服务器运行**：测试前必须启动API服务
2. **网络连接**：需要能够访问localhost:8000
3. **依赖安装**：确保httpx等依赖已安装
4. **结果文件**：测试结果会自动保存，注意清理旧文件

## 相关文件

- `scripts/auto_test_first_message.py` - 主测试脚本
- `scripts/run_auto_test.sh` - Shell包装脚本
- `scripts/test_result_*.json` - 测试结果文件
